# CatanX photoreal terrain set v1

These textures are original CatanX production assets. They do not contain or
derive from CATAN artwork.

## Source albedos

| Stem | Source | Date | Notes |
| --- | --- | --- | --- |
| `alpine_rock` | OpenAI built-in image generation | 2026-07-22 | Neutral top-down alpine rock scan specification. |
| `wheat_stubble` | OpenAI built-in image generation | 2026-07-22 | Neutral top-down harvested-field scan specification. |
| `red_clay` | OpenAI built-in image generation | 2026-07-22 | Neutral top-down compacted red-clay scan specification. |
| `dune_sand` | OpenAI built-in image generation | 2026-07-22 | Neutral top-down coastal sand scan specification. |
| `meadow` | Existing original CatanX source asset | Prior to 2026-07-22 | Companion maps regenerated by the current pipeline. |

All generated prompts required flat overcast/cross-polarized lighting,
orthographic top-down framing, edge-to-edge material coverage, no objects, no
text, no watermark and no baked directional shadow.

## Derived channels

`tools/build_pbr_from_albedo.py` creates the game-ready companion channels:

- neutralized JPEG albedo;
- tangent-space WebP normal;
- JPEG roughness;
- JPEG ambient occlusion;
- JPEG height.

The derived maps are deterministic and may be replaced independently by
artist-authored or photogrammetry channels without changing runtime code.
