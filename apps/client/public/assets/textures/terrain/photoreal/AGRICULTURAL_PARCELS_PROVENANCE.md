# Agricultural parcel materials

- `wheat_rows_*_v1`: generated with the built-in Imagegen tool from a production prompt requesting a seamless, orthographic, muted mature wheat field with narrow cultivation rows and diffuse lighting.
- `ploughed_field_*_v1`: generated with the built-in Imagegen tool from a production prompt requesting a seamless, orthographic European ploughed field with restrained straw residue and diffuse lighting.
- Source PNG files are archived under `assets-src/textures/agriculture/`.
- Normal, height, roughness and AO companions were derived locally with `tools/build_pbr_from_albedo.py` and deliberately use conservative strengths.
- No external Catan artwork or branded asset is included.
