# H6 — Biomes avancés et événements

**Statut :** polish biomes renforcés — prêt pour revue.

## Améliorations biomes (demande visuelle)

| Biome | Changement |
|---|---|
| **Toundra** | Sapins modérés (10–15), moutons ambiants, neige |
| **Jungle** | Palmiers `palm_a/b` + petites bananes sous la couronne |
| **Marais** | Mares + roseaux (plumes / tiges penchées), troncs morts |
| **Ruines** | Murs / arches / colonnes / tour — kit dense |
| **Glacier** | Blocs de glace denses + neige + mares d’eau de fonte |
| **Volcan** | Cône montagneux (échelle alpine) + lave + rochers |
| **Lacs / Rivière** | Aucune décoration (eau) |
| **Sacré** | Retiré de la scène H6 (fallback générique si présent en carte) |
